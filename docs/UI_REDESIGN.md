# 课堂工作区界面重构

## 使用范围与信息架构

在 React 19 / TypeScript / Vite 基础上重构，继续使用原有 FastAPI API。哈希导航兼容 GitHub Pages 的仓库子路径，刷新子页面不需要服务器重写规则。

页面：工作台 → 实时课堂 → AI 课堂分析；事件中心支持本次课堂的筛选搜索，历史课堂保存结束后的报告，工作区设置维护课堂上下文。

摄像头和语音状态由 `useClassroom` 维护。实时视频元素始终挂载，非实时页面通过 `hidden` 隐藏，避免导航卸载摄像头。正在观察时，其他页面显示返回课堂入口，刷新页面会触发离开提醒。更换镜头期间暂停新的分析请求，避免把上一镜头标记带入新画面。

## 组件与视觉

- `Shell`：品牌、学校、时间、事件通知入口、观察员信息及响应式侧栏。
- `Dashboard`：实际会话数据、近七天历史趋势、行为分布和开始步骤。
- `LiveClassroom`：画面优先的观察空间、语音/照片配置与时间轴。手机首次使用时照片上传前置。
- `Analysis` / `ReportView`：行为分布、课堂总结、逐人明细及导出。
- `EventList` / `EventsPage`：统一事件样式、正常/异常筛选及关键词检索。
- `HistoryPage` / `SettingsPage`：本机归档和上下文配置。
- `ui`：统一卡片、指标、徽标、空状态和操作按钮。

视觉采用深蓝侧栏、浅色工作区、青绿强调、琥珀异常提示；删除旧动画、发光扫描及未使用数字人样式。图表使用原生 CSS，图标继续使用 Lucide，没有引入新框架或外部字体依赖。兼容 1920、1366、1024 和 390 像素宽度；提供键盘焦点、移动菜单、语义化表格及减少动态效果选项。

## 数据口径

今日与趋势统计仅覆盖当前浏览器保留的课堂。正常记录占比 = 正常事件条数 / 全部事件条数，不推断专注度。画面可见人数不等于考勤。没有实际数据时展示空状态，不填充演示学生或虚构评分。当前未提供全校账户、角色权限、教师行为评价及统一教室管理。

结束时归档课堂上下文和报告，浏览器最多保留 30 条，存储失败会显示导出提示。历史不保存摄像头原始图像。刷新页面可以查看已结束课堂的本机报告，但不能恢复未结束的摄像头会话。

## 验证

- 前端单元测试：摄像头回退、移动端音频、时间同步、历史损坏容错、多人事件去重、正常率口径、事件筛选搜索。
- 后端回归：原有接口与服务测试。
- 本地 Edge 自动化：四种屏幕宽度的六页导航、页面宽度溢出和运行时错误；使用模拟摄像头和模拟 API 检查上传 → 开始 → 正常记录不请求语音 → 异常请求语音 → 暂停/继续 → 跨页保持摄像头 → 结束关闭摄像头 → 报告归档 → 刷新回看 → JSON 导出。
- 人工视觉检查：工作台、实时页、移动端布局及有数据的报告。
- 本地及 Pages CI 生产构建。

浏览器自动化不等于真实手机的摄像头或扬声器验收。手机设备应另行检查后置镜头、音量、语音授权和横竖屏；云端大模型的识别准确性不在 UI 测试范围内。
